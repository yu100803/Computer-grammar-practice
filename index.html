About CSS

What is CSS

  1. CSS ("Cascading Style Sheets") determines how the elements in our XHTML documents are displayed and formatted.
  2. By using CSS, we separate the content of a web page from the presentation (format and styling) of that content.
  3. CSS enables us to make all pages of our website look similar and consistent.
  4. The power of CSS is that it allows us to make site-wide formatting changes by making edits to a single file.
